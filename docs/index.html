Motivation

Currently I'm building Motivation, a self-hosted personal dashboard as a PWA in vanilla web components, using a lot of modern webbrowser API's.
It uses a service worker for offline-first, a web worker with a SQLite replica in OPFS that syncs to my home server, barcode scanning through the camera and Web Push for notifications.
It also uses a sideloaded Kotlin app to bridge to Android Health Connect.
At home I run a local LLM for in app features like estimating meal nutrition from photos and/or descriptions.
